## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `kemuri/nearfield`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage labels without aliases. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout with `CONTEXT.md` and `docs/adr/` at the repository root. See `docs/agents/domain.md`.

### Production releases

Every production release must update the trynearfield.com changelog with its version,
release date, and a short summary of shipped changes. Follow `docs/production-releases.md`
when packaging or publishing a release.
